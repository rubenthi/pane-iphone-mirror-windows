# Commissioner

`commissioner-latin.woff2` is the unmodified Latin variable-weight font from
`@fontsource-variable/commissioner` 5.3.0 (`commissioner-latin-wght-normal.woff2`).
It is 36,700 bytes. Copyright and SIL Open Font License terms are included in
`COMMISSIONER-LICENSE.txt`. Font project: https://github.com/kosbarts/Commissioner.

Pane serves this asset locally and includes it in the Windows package. It does
not request a font CDN. Native fallbacks cover glyphs outside this Latin subset.
