STEP BY STEP

Make yourself at home.

A complete guide for iOS 27. Keep your iPhone nearby and unlocked.

01 Check the prerequisites
  • Windows 10 or 11, 64-bit, with the Microsoft Edge WebView2 Runtime. This powers the floating window. Chrome/Edge is a fallback if the native runtime is unavailable.
  • An iPhone running iOS 27 or later. Check Settings → General → About → iOS Version. Version eligibility is not a guarantee that your model has been tested.
  • Apple Devices from Microsoft Store, opened at least once. It supplies the Apple USB service.
  • A data-capable cable matching your phone's port. A charging-only cable will not work.
  • Internet for the first developer-image download and Pane updates; the mirror itself stays on your USB/local network.

No Python, Mac, paid account, jailbreak, or separate iPhone app is needed for the packaged Pane executable.

02 Connect and trust this PC
  1. Open Apple Devices on Windows.
  2. Connect the iPhone directly with the data cable. Unlock it.
  3. Select the phone in Apple Devices and approve Trust if requested.
  4. On the phone, tap Trust in the computer-trust prompt and enter your passcode yourself.
  5. Return here and press Refresh. The device should appear below.

If it only charges, try another data cable or USB port. If Apple Devices cannot see it, fix that connection before starting Pane.

Apple: trusting a computer ↗
03 Enable Developer Mode
  1. On the iPhone, open Settings → Privacy & Security → Developer Mode.
  2. Enable it, accept the restart, then unlock the phone again.
  3. Confirm enabling Developer Mode after reboot and enter your passcode if asked.
  4. Reconnect the cable and keep the phone unlocked.

Missing the switch? Apple says it appears after initiating developer pairing or previously pairing with a Mac. Trust the PC first and attempt the connection once. Pane cannot guarantee it will expose the switch. Managed-device restrictions may also require your administrator.

Developer Mode still missing? Install AltStore Classic

Installing a development-signed app can help expose Developer Mode. This is an optional workaround, not a guaranteed fix for every iOS 27 device or managed phone. Pane itself does not require AltStore or an Apple Account.

  1. Read AltStore's official Windows installation guide. Choose AltStore Classic with AltServer, not AltStore PAL.
  2. Install the Apple-distributed iTunes and iCloud versions linked by that guide. Its standard instructions exclude Microsoft Store builds; consult its linked troubleshooting alternative if you must retain Store iCloud. Review compatibility before replacing an existing Apple setup.
  3. Download AltServer for Windows from altstore.io, extract its ZIP, run Setup, then launch AltServer as administrator. Permit private-network access if needed on your trusted network.
  4. Connect and unlock the phone, approve Trust, and enable iTunes Wi-Fi sync.
  5. From AltServer's tray icon, choose Install AltStore → your iPhone. Complete Apple Account authentication yourself in AltServer. Never enter those credentials in Pane or a support report.
  6. Once installed, on the phone open Settings → General → VPN & Device Management (the label may vary), and trust your own developer profile. Try opening AltStore.
  7. Revisit Settings → Privacy & Security → Developer Mode. Enable it, restart, and confirm after unlocking. Return to Pane's Cable connection.

If the switch is still missing, do not assume installation succeeded or that restrictions were removed. Check AltStore's installation errors and Apple's Developer Mode guidance. A managed device may require its administrator. This workaround has not been hardware-verified by this fork on iOS 27.

If you keep using AltStore with a free Apple Account, sideloaded apps generally require refreshing within seven days; see AltStore's getting-started guide. That maintenance requirement belongs to AltStore, not Pane's Windows updater.

Developer Mode enables developer-only capabilities; turn it off when you no longer need them.

04 Start your first USB mirror
  1. Choose Cable and select your phone in Device.
  2. Press Start mirroring. Stay unlocked while the connection opens.
  3. The first connection may download and mount a matching developer image. Keep internet and USB connected; read the status instead of repeatedly starting new sessions.
  4. When video appears, try scrolling on a harmless screen. Open Notes and test a short line of text.

The first real video frame sets Pane's proportions to the connected display. Before then, it uses a standard portrait outline.

05 Mouse, keyboard & window controls
  • Click to tap; drag to swipe. Right-click the mirror for Home.
  • With Keyboard → iPhone enabled, focus the mirror and type in an iPhone text field. Ctrl+V transfers laptop text or a PNG to the iPhone before pasting. Ctrl+C/X/A/Z remain iPhone command shortcuts. Type a letter or press F2 to enter typing mode; F2, Esc or Home returns to navigation, where Space goes Home.
  • The arrow opens or hides this menu over the phone without widening the window. Drag the pane label to move the window. The crosshair pins it on top; − minimizes and × closes.
  • Use the Controls section for Home, volume, rotation, and fullscreen. Esc exits fullscreen.

Try input in Notes before sensitive apps. Closing Pane stops the stream; a verified pending update installs after exit.

06 Optional: pair over Wi-Fi
  1. Get USB mirroring working first. Keep the trusted cable connected.
  2. Connect the PC and iPhone to the same trusted Wi-Fi/LAN; avoid isolated guest networks.
  3. Choose Wi-Fi and press Set up Wi-Fi. Wait for the successful pairing message.
  4. Unplug USB, keep the phone unlocked, and press Start mirroring with Wi-Fi selected.

If discovery fails, reconnect USB to confirm pairing. Check that VPNs, router client isolation, or firewall rules are not blocking local discovery. Use a Private Windows network profile only on a network you trust; do not disable the firewall globally.

07 Troubleshooting & updates
  • No device: reopen Apple Devices, unlock, reconnect, and Refresh. Test a known data cable.
  • Black video: verify Developer Mode, close camera/microphone apps, then try Restart screen. Read the reported error.
  • Decoder unavailable: update the WebView2 Runtime (or Chrome/Edge in fallback mode) and your graphics driver. HEVC/WebCodecs support depends on the browser, GPU and Windows codecs; do not assume a connected device means video is supported.
  • Connection lost: unlock the phone and check the cable/network. Refresh and start again.
  • Updates: Pane checks this public fork on launch, verifies the download, and installs after you close it. Reopen Pane to use the new version; the old executable is retained for rollback.
