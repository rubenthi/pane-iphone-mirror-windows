# iPhone setup

For Pane 2.0, open the sidebar's **Connection** tab and choose **Open setup**.

Follow the [current setup and companion-signing guide](companion-setup.md): trusted USB, Developer Mode reveal, signed Pane companion installation, on-device enable/restart/confirmation, USB/Wi-Fi binding, then Bluetooth.

The file-transfer companion runs on iOS 17+. Pane's pinned screen-streaming dependency still requires iOS 27+; see [device compatibility](compatibility.md). Turning on Developer Mode does not by itself establish hardware support for mirroring or Bluetooth transfers.
