Pane 2.5.7 retains the existing Windows device stack and iPhone companion 2.6.0 (build 6). The desktop separates Apple’s Wi-Fi routes from physical USB connections, verifies an existing trusted session before reporting a paired phone, and distinguishes an unavailable Developer Mode status from an explicit off setting.

Video playback uses fewer temporary objects when parsing ordinary HEVC frames. File transfer history redacts internal error details and preserves completed transfers when a delayed phone response arrives. Development notification shortcuts open the development edition. A disconnected notification session can establish a fresh subscription.

Use the Windows installer or existing updater to preserve your profile and rollback copy. For iPhone installation or renewal, connect the phone by USB and use Settings → Setup & signing with the same Apple Account and team. A desktop update alone does not reinstall the companion.
