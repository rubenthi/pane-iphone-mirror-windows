Pane 1.4.0 for Windows x64

- Preserves the existing Developer Mode USB/Wi-Fi video, touch, gestures and keyboard control.
- Adds a control-method selector for Bluetooth cursor control with a separate AirPlay receiver and iPhone AssistiveTouch.
- Adds Bluetooth media audio reception on the laptop and in-app iPhone notifications through ANCS.
- Stops automatically lowering iPhone media volume, which would also silence Bluetooth media audio.
- Adds a Phone Link handoff for supported hands-free calls and laptop microphone use. General microphone injection into iPhone apps is not implemented.
- Includes the self-contained Windows Bluetooth helper. Bluetooth hardware compatibility and simultaneous AirPlay/Bluetooth audio require verification on your laptop and iPhone.

Existing installed copies from rubenthi/pane-iphone-mirror-windows check for updates when launched. Wait for the verified update message, close Pane normally, then reopen it. A backup of the previous executable is retained. The separate source fork has automatic updates disabled.
