Pane 1.7.5 for Windows x64

Pane automatically selects the paired Bluetooth endpoint that matches the mirrored iPhone and shows that phone in the audio picker. Existing Windows pairings are preserved. Bluetooth playback uses the v1.7.4 receiver, connection order and retry behavior. The picker change is limited to which paired device Pane shows. The reported Apple Music playback issue remains unresolved.

The mirror uses the iPhone's primary display dimensions to remove trailing encoder padding. A one-pixel border surrounds the visible screen. The window content follows the viewport during corner drags, and the spaces between the three window buttons show the desktop. Minimize uses the Windows taskbar command and respects system animation preferences.

Trackpad scroll deltas now move one continuous touch on the iPhone until the gesture ends. This removes the wait for a separate eight-step swipe on every batch of wheel input.

To update, open Pane, allow the download to finish, close normally and reopen. The connection panel and the executable's Product version show 1.7.5.
